Version History

Recorded updates to the Packard Toolkit. Earlier entries retain their original tool versions and recorded dates.

Packard Toolkit v2.10.0 — September 17, 2026

Added Intake Review with copyable client details, review flags, failed-work-attempt detection, and dismissible review items; refined Intake Checker layout/report separation.

Packard Toolkit v2.9.2 — September 17, 2026

Added a two-column Intake Checker workspace and source-aware Find in Intake actions; removed the debug UI. Temporarily removed Intake Checker and Fax Sender from navigation while preserving direct URLs. Validation rules are unchanged.

Packard Toolkit v2.9.1 — September 16, 2026

Added plain-text DeLorean clipboard parsing alongside Markdown support and prevented validation after a zero-section parsing failure.

Packard Toolkit v2.9.0 — September 16, 2026

Added deterministic V1 intake validation with required-field and conditional checks, an explainable report, and the existing parsed-structure debug view.

Packard Toolkit v2.8.0 — September 16, 2026

Added Intake Checker to parse pasted DeLorean intake text locally, with a summary and structured debug view. Intake validation rules are not yet included.

Packard Toolkit v2.7.0 — September 15, 2026

Added recent Fax History to the Fax Sender and improved the circular-arrow icon and related UI.

Packard Toolkit v2.6.0 — September 15, 2026

Added centralized Version History with access from Settings and page footers. Moved Fax Sender history off the main fax interface. Fixed Email Sender → Fax Sender navigation and verified navigation links across the Toolkit.

Fax Sender v2.5.2 — September 15, 2026

Streamlined document and fax-status UI, removing redundant pre-send counters and destination text while making document cards the primary status display.

Fax Sender v.2.5 — September 15, 2026

Combined contact search and manual fax entry into one compact destination control with an overlay dropdown, readable numbers, selected-state clearing, and icon refresh. Batch destination locking and fax processing are unchanged.

Fax Sender v.2.4 — September 15, 2026

Added a searchable RingCentral personal-contact fax destination picker with separate fax choices, manual entry fallback, and existing batch destination locking.

Fax Sender v.2.3 — September 15, 2026

Updated fax labels to Processing, Submitted, and Sent; clarified status-checking copy and removed the duplicate completion summary. Sending, polling, and retry safety are unchanged.

Fax Sender v.2.2 — September 15, 2026

Fixed the browser timer binding error that prevented automatic fax status tracking. Improved safe status lookup errors and added browser regression coverage. Fax submission behavior is unchanged.
